# Pigeon AI API

Standard-library Python scaffold for the Pigeon AI backend. It exposes the requested REST API routes for authentication, user profiles, pigeon records, pedigrees, breeding, health, races, AI analysis, weather, uploads, knowledge, and admin operations.

## Run locally

```bash
python app/main.py
```

The development server listens at <http://127.0.0.1:8000>.
