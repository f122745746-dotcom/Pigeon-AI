# Pigeon AI（和平鴿智慧體）

Pigeon AI is a planned full-stack racing pigeon ecosystem for Taiwan, combining AI assistance, loft management, pedigree analysis, racing operations, knowledge-base workflows, and industry information services.

## Product scope

The v1.0 product vision targets Android, iOS, and a Web Admin backend with the following core modules:

- AI Pigeon Assistant
- Loft management
- AI breeding center
- Racing center
- Real-time weather and flight-risk center
- Racing pigeon knowledge base
- Industry navigation

## Technical direction

- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Cache:** Redis
- **Storage:** AWS S3
- **AI services:** OpenAI GPT, OpenAI Vision, Whisper STT
- **Push:** Firebase Cloud Messaging
- **Authentication:** Email OTP, Google Login, Apple Login, LINE Login
